# 1.5.11 Automation 容量与积压恢复

## 目标

修复持续运行后浏览器名额等待、同步线程和清理互相阻塞的问题；按用户授权提高内存预算，恢复普通推理和后台维护，并收尾没有有效执行租约的历史操作。

## 范围与影响文件

- `automation/`：后台同步工作与清理使用独立有界执行资源；取消传播至浏览器名额等待，名额等待具备总时限；前台保留浏览器容量，内部健康检查观测任务进度。
- `deploy/gitops/automation-runtime-resources.yaml`：共享 Automation/Arena 内存上限均为 6Gi、request 均为 2Gi；共享浏览器预算为 4，保持 CPU、代理及厂商限流。
- `backend/observability/`：周期对账过期 RUNNING，仅关闭没有匹配有效执行租约的生命周期/注册操作，保留仍有所有权的操作。
- 同步版本、针对性并发/取消/真实 PostgreSQL 回归、发布验收记录。

## 非目标与兼容

不改 OpenAI 客户端契约、账号权限、代理绑定、注册计划或保活周期；不恢复生成探活和模型可用性判定；DeepSeek/Qwen 保持停用。不以删除历史数据掩盖积压，不新增数据库结构或外部服务。

## 验收与测试

1. 默认工作线程被同步名额等待占用时，清理和 reaper 仍能完成；取消后等待工作退出，不再取得或泄漏名额。
2. 后台排队与实际执行均有界，取消不提前释放仍在运行的同步工作名额；保留 ContextVar 中的关联信息。
3. 浏览器总量不超过预算，后台留出前台容量；健康检查不访问厂商、不生成文本。
4. 对账关闭孤立旧操作，保留近期操作及匹配当前有效租约的操作；重复执行幂等、并发节点由事务 advisory lock 协调。
5. 全量 Automation、Backend、Ruff、Web 构建与版本契约通过；CI/GitOps、运行版本/资源/健康、少量真实输出和维护推进分别验收。

## 发布与回滚

占用新补丁版本 1.5.11，所有组件版本一致，使用新的不可变镜像。沿既有部署授权提交、CI 和 Argo 发布。回滚使用 1.5.10 不可变镜像及对应资源补丁；不回退已完成的历史终态修正，无数据库迁移。连续运行稳定性需要后续真实流量观察，短窗口不扩大为全部账号和客户端验收。

## 1.5.12 运行验收后发现的流队列补丁

- **目标/范围**：1.5.11 已上线恢复普通输出，运行指标显示 MiniMax 流消费者逐帧 offload 导致数千次线程任务；默认线程池占满时，消费者还会等待生产者占用的同一线程资源。修复 `minmax_api_actions._api_stream` 的消费等待。
- **实现边界**：保留 64 项有界队列、2MiB 单帧限制、原顺序、错误/凭据补丁和取消关闭；使用线程安全通知唤醒异步消费者，读取队列不再 offload。
- **影响文件**：MiniMax API 流、对应并发回归、全端版本和本报告；不更改部署预算、OpenAI/厂商载荷或数据库。
- **验收/测试**：默认执行器仅一个线程时，生产者和消费者仍能完整传递超过队列容量的 100 帧；旧代码确定超时，新代码通过；全量质量/版本及 CI、运行输出验收。占用 1.5.12，不复用已发布 1.5.11 制品。回滚点为 1.5.11，保留已生效的内存扩容及历史终态修正。

## 1.5.13 入库验证路由与滚动更新契约

- **目标**：修复已有单账号验证接口未匹配长请求路由、约 15 秒被网关取消的问题；管理台统一调用已有 `/account-probes`，保留旧 API；将滚动配额要求纳入版本化部署。
- **范围/文件**：`web/src/lib/api.ts`、`deploy/gitops/` 的精确 POST 路由及 namespace quota 补丁、CI 的补丁同步、版本值与部署契约回归。
- **边界**：验证业务仍为每账号一次，不重置已消耗预算、不自动反复生成；不扩大全部管理接口超时、权限、厂商/代理范围。新 Edge 账号仅按原导入流程独立入库，其他账号凭据保持。
- **验收**：旧 UUID 验证 POST 路由具有 300 秒超时，普通 Read/非验证路径不匹配；管理台默认/指定模型使用同一已有接口；完整 Kustomize 渲染保留其他路由；namespace request memory=12Gi、limit memory=32Gi、limit CPU=12，正常 Pod 预算不再扩大。
- **测试/发布**：精确路径正反例、完整渲染、Web/Automation/Backend/版本契约与 CI/Argo；占用 1.5.13 不可变镜像，回滚 1.5.12 应用，保留修正的 namespace 配额。Arena 的实际有效生成独立记录，不把导入或路由修复等同于恢复。
