# WEB 桥接遗留问题收尾（Qwen 除外）

## 目标与授权

用户要求处理 2026-10-03 验收报告的全部遗留事项，Qwen 除外。沿用已授权的实现、提交、现有 GitOps 部署和现有账号真实测试。实施起点为 0.25.2 / 129dbf9、工作树干净。修复候选先占用 0.25.3，若实际新增公共能力则按 SemVer 调整为 minor。

后续 0.25.3–0.25.7 修复已部署；最终真实验收、已支持/未支持能力、入口和厂家限制、性能回退与回滚见 [处理记录](../reports/WEB_BRIDGE_FOLLOWUP_2026-10-03.md)。本规格保留各候选实施前的范围，不将仍有外部限制的事项记成全部解决。

## 范围与影响文件

1. Arena：在首个有效输出之前，凭据拒绝可以有限次数换用其他账号；保留认证失败隔离、恢复和租约释放，禁止复用失败账号或输出后重试。影响 Provider retry / coordinator 及测试。
2. LongCat：追踪真实附件内容、上传对象、会话与模型输入，修复已证实的桥接问题；普通用户图片和工具结果图片均须实测，不能在 prompt 暗示答案。影响 LongCat Web/API mapper、上传、decoder 和媒体回归。
3. Grok：拆分 runtime/页面/连接/首输出时间，定位等待并降低可控开销；保留硬超时、取消清理和工具契约。影响 Grok Runtime、日志/指标及测试。
4. Read：核对剩余纯读事务、SQL 次数、目录响应体积和真实网络拓扑，实施保持契约的优化；必要时调整可回滚的无状态服务调度，不迁移 PostgreSQL/PV。影响 Query Services、catalog、GitOps 和集成测试。
5. 公网：验证 direct/public 的 OpenAI JSON 错误和 SSE 终态，覆盖 400/401/403/404/429/502/503/504；定位并修复现有可管理入口的透传或压缩问题。无生产故障注入或公开测试后门。
6. 验收：七家所选模型的核心 text/function、已声明 native search/reasoning/media、长历史、失败、取消与有限并发，以及现有 namespace/custom。不支持的能力要求明确拒绝，不新增全量协议。

## 非目标和兼容

不创建外部账号、不处理 Qwen、不执行调用方工具、不移除已有功能、不降低图片验收标准，不修改公共 API/权限/数据结构。所有诊断只含阶段/耗时/事件计数，不保存凭据或用户正文。新外部凭据、不可逆操作或无法访问的外部配置按 AGENTS.md 停止条件处理，并继续完成其他独立工作。

## 验收与测试

- 单元/真实 PostgreSQL 回归覆盖换号次数、排除账号、输出后不重试、租约/恢复、媒体字节与对象身份、纯读默认值和写事务保留。
- Backend/Automation/Web、源码/JAR/镜像版本门禁通过；部署后 CI/GitOps/Pod/日志/API 证据齐全。
- 限定模型/协议/feature 的临时 Key，成功和失败尝试独立记录，finally 清理；七家能力矩阵区分 PASS、明确 UNSUPPORTED、上游限制和确实未验证。
- Read 同入口基线和部署后比较，并补有限并发；图片至少多种颜色/尺寸和一种非纯色内容，期望值不进入 prompt；Grok 分阶段证据不得只靠延长超时。
- 公开/直连错误实测比较 status、Content-Type、OpenAI error code/request_id 和 SSE 终态；无法触发的状态以本地受控测试和已覆盖入口证据分别记录。

无破坏性迁移，回滚到 0.25.2 四组件不可变镜像与原有无状态服务调度。各部署候选独占 SemVer，不能覆盖制品；报告逐项给出修复、真实验证、剩余外部限制和回滚点。

## 0.25.6 收尾范围

- GLM 46 条历史在 0.25.5 的真实 WEB 调用中复现丢失上下文；仅提供完整 native messages/history tree 仍失败，将相同原始历史放入当前签名 prompt 后通过。修复 `glm_runtime.py`，多轮 prompt 保留角色标记、工具内容和完整文本，单轮及 typed 附件保持原有行为，禁止注入预期答案或截断历史。单元验证不修改调用方对象，部署后复测 developer/user 两种历史和 SDK 工具循环。
- 实际 Codex command 验收被客户端本地命令策略拒绝，后端已接收并回传工具错误。保留该失败证据；使用只读 `view_image` 验证真实 agent 的图片工具闭环，保留失败时的 CLI 输出，禁止绕过本地策略。
- 全量 `/v1/models` 继续区分服务端处理、跨节点 RTT 与响应体传输成本，依据实际测量处理，保留全部字段和权限过滤。
- Cloudflare Worker 为未发布候选；当前不修改其路由。公网 Cloudflare 502/524 错误格式列为入口遗留限制，SSE 心跳和取消在现有入口验收。
- 本候选无数据库/API/权限变更，回滚点为已验证的 0.25.5 四组件不可变镜像。

## 0.25.7 复测发现的缺陷

- `SmartContextWindowManager` 的默认 32 条裁剪导致早期 user 内容丢失。按 Responses 既有 `truncation` 契约，默认和 disabled 保留完整输入；仅显式 auto 采用既有裁剪策略；厂商明确声明的 message 上限在 disabled 时继续返回明确错误，现有 token/request-size 校验保持。验证早期 user、developer、工具调用/结果边界及真实 46 条历史。
- MinMax 原生图片 UI capture 先发送生成再重放，复现 session_not_idle。捕获阶段阻断 fetch/XHR 生成，结束或失败恢复 hook，禁止复用旧捕获；保留全部图片、完整调用方 context 与所选模型。删除相关正文/附件/URL query 诊断日志，维持上传和流式路径。验证捕获无发送、正常请求不受影响、失败清理、完整 replay，部署后复测用户/工具 OCR 和工具循环。
- 修复使用新 patch 候选 0.25.7；无 schema 变更。已通过的 0.25.6 SDK/native 和已失败尝试分开保留，滚动前等待本任务活动请求完成；部署后只重测改动涉及的契约及运行态。
