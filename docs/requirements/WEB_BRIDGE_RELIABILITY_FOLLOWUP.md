# WEB 桥接遗留问题收尾（Qwen 除外）

## 目标与授权

用户要求处理 2026-10-03 验收报告的全部遗留事项，Qwen 除外。沿用已授权的实现、提交、现有 GitOps 部署和现有账号真实测试。基线为 0.25.2 / 129dbf9；当前工作树干净。修复候选先占用 0.25.3，若实际新增公共能力则按 SemVer 调整为 minor。

## 范围与影响文件

1. Arena：在首个有效输出之前，凭据拒绝可以有限次数换用其他账号；保留认证失败隔离、恢复和租约释放，禁止复用失败账号或输出后重试。影响 Provider retry / coordinator 及测试。
2. LongCat：追踪真实附件内容、上传对象、会话与模型输入，修复已证实的桥接问题；普通用户图片和工具结果图片均须实测，不能在 prompt 暗示答案。影响 LongCat Web/API mapper、上传、decoder 和媒体回归。
3. Grok：拆分 runtime/页面/连接/首输出时间，定位等待并降低可控开销；保留硬超时、取消清理和工具契约。影响 Grok Runtime、日志/指标及测试。
4. Read：核对剩余纯读事务、SQL 次数、目录响应体积和真实网络拓扑，实施保持契约的优化；必要时调整可回滚的无状态服务调度，不迁移 PostgreSQL/PV。影响 Query Services、catalog、GitOps 和集成测试。
5. 公网：验证 direct/public 的 OpenAI JSON 错误和 SSE 终态，覆盖 400/401/403/404/429/502/503/504；定位并修复现有可管理入口的透传或压缩问题。无生产故障注入或公开测试后门。
6. 验收：七家所选模型的核心 text/function、已声明 native search/reasoning/media、长历史、失败、取消与有限并发，以及现有 namespace/custom。不支持的能力要求明确拒绝，不新增全量协议。

## 非目标和兼容

不创建外部账号、不处理 Qwen、不执行调用方工具、不移除已有功能、不降低图片验收标准，不修改公共 API/权限/数据结构。所有诊断只含阶段/耗时/事件计数，不保存凭据或用户正文。新外部凭据、不可逆操作或无法访问的外部配置按 AGENTS.md 停止条件处理，并继续完成其他独立工作。

## 验收与测试

- 单元/真实 PostgreSQL 回归覆盖换号次数、排除账号、输出后不重试、租约/恢复、媒体字节与对象身份、纯读默认值和写事务保留。
- Backend/Automation/Web、源码/JAR/镜像版本门禁通过；部署后 CI/GitOps/Pod/日志/API 证据齐全。
- 限定模型/协议/feature 的临时 Key，成功和失败尝试独立记录，finally 清理；七家能力矩阵区分 PASS、明确 UNSUPPORTED、上游限制和确实未验证。
- Read 同入口基线和部署后比较，并补有限并发；图片至少多种颜色/尺寸和一种非纯色内容，期望值不进入 prompt；Grok 分阶段证据不得只靠延长超时。
- 公开/直连错误实测比较 status、Content-Type、OpenAI error code/request_id 和 SSE 终态；无法触发的状态以本地受控测试和已覆盖入口证据分别记录。

## 回滚与交付

无破坏性迁移，回滚到 0.25.2 四组件不可变镜像与原有无状态服务调度。各部署候选独占 SemVer，不能覆盖制品；报告逐项给出修复、真实验证、剩余外部限制和回滚点。
